# MediClinic PWA

Aplicación web progresiva desarrollada en React para la gestión de pacientes de una clínica.

## Funcionalidades

- Login con usuarios fijos.
- Gestión de pacientes.
- Registro de pacientes.
- Búsqueda por nombre, apellido y CC.
- Persistencia mediante localStorage.
- Instalación como PWA.
- Funcionamiento offline mediante Service Worker.

## Tecnologías

- React
- Vite
- JavaScript
- vite-plugin-pwa
